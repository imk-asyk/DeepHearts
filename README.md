# DeepHearts
A MLP version of AI for Windows Hearts.
# Structure
#### Input: 46 dimensions
- Stats (other players without a certain card type 3 * 4 + all player scores 4)
- Board (one-hot type + number 5 * 3 (max))
- Played card count of 4 types
- Having spade Q/K/A in hand
- passing mode (one-hot for 3 directions)
#### Hidden: \[512, 256\], ReLU
#### Output: 52 dimensions (all cards) -> Softmax -> multinomial
- Added a MinMaxNorm(-4, 4) before Softmax to avoid Softmax errors
- Masked illegal operations after Softmax
#### Training: log prob, cofactor = lost points for the whole round
- Optimizer: Adam (steps every batch)
- Scheduler: CosineAnnealingLR (steps every epoch)
# Results
- VS Random (1v3): about 2.1 (dspGuru 2.4)
- VS dspGuru: about 6.1 (E(X) >= 6.5 due to the moons)
